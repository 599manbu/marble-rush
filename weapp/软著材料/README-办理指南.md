# 软件著作权登记 · 办理指南

> 目标：为《赛球弹珠竞速游戏软件 V1.0.0》办理《计算机软件著作权登记证书》，用于微信小游戏备案/提审。

## 一、本目录材料

| 文件 | 用途 | 状态 |
|---|---|---|
| `01-登记信息表.md` / `.pdf` | 在线申请表逐项填写参考 | 补全个人信息即可 |
| `02-软件说明书.md` / `.pdf` | 软著申请材料中的「文档」 | 已含截图，约 10 页 |
| `03-源程序.pdf` | 软著申请材料中的「源程序」 | 35 页，每页 50 行，带页眉页码 |
| `README-办理指南.md` | 本文件 | — |

软著要求：源程序与文档各提交「前 30 页 + 后 30 页，共 60 页」；**不足 60 页的全部提交**。
本项目源程序 35 页、说明书约 10 页，均不足 60 页，因此**全部提交**即可。

## 二、申请前准备

1. **身份证正反面**：拍照或扫描，清晰、四角完整。
2. **补全信息**：把 `01-登记信息表.md` 里的姓名、身份证号、电话、邮箱、地址补全（或告诉我，我帮你填进 PDF）。
3. **确认软件全称**：`赛球弹珠竞速游戏软件`，版本 `V1.0.0`。登记后名称不可随意更改。

## 三、在线申请步骤

1. 打开 **中国版权保护中心** 软件著作权登记系统：
   https://register.ccopyright.com.cn
2. 注册账号 → 实名认证（个人需身份证信息）。
3. 选择「软件著作权登记」→ 新建申请。
4. 按 `01-登记信息表.md` 逐项填写：
   - 软件全称、简称、版本号
   - 开发完成日期、发表状态
   - 开发方式（独立开发）、权利取得方式（原始取得）、权利范围（全部权利）
   - 软硬件环境、编程语言、源程序量
   - 主要功能与技术特点
   - 权利人信息、联系人信息
5. 上传/填写材料说明，提交申请。
6. 系统生成《计算机软件著作权登记申请表》，**打印后手写签字**。
7. 按系统提示提交材料（现在多为**在线提交电子件**，部分地区/情形需邮寄纸质件，以提交页面提示为准）：
   - 申请表（签字）
   - 源程序：`03-源程序.pdf`（或按系统要求单面打印）
   - 文档：`02-软件说明书.pdf`
   - 身份证明：身份证正反面
8. 等待受理与审查。

## 四、时间与费用

| 项目 | 说明 |
|---|---|
| 登记费 | **免费**（2017 年起停征） |
| 普通流程 | 约 **30–60 个工作日** |
| 加急服务 | 第三方代理提供，按天数收费（几百至上千元），可缩短到 3–15 个工作日 |
| 电子版权认证 | 3–5 个工作日、几百元；**不能替代软著**，但可作为备案期间的临时版权证明 |

> 如果微信备案后台催得紧，可以先办电子版权认证顶上，同时办软著。

## 五、打印与格式要求（如提交纸质件）

1. **A4 单面打印**，不要双面。
2. 源程序每页不少于 50 行；文档每页不少于 30 行（图片页除外）。
3. 每页页眉需有：**软件名称 + 版本号 + 页码**（`03-源程序.pdf` 已自动带）。
4. 装订顺序：申请表 → 身份证明 → 源程序 → 文档。
5. 申请表签字处必须**手写签名**，与身份证姓名一致。

## 六、常见驳回原因

- 软件名称与申请表、页眉、说明书不一致
- 源程序页数不足、每页行数不足 50 行
- 文档没有截图或与软件实际功能不符
- 身份证照片模糊、反光、缺角
- 申请表未手写签字
- 开发完成日期晚于申请日期（日期要合理）

## 七、登记完成后

1. 拿到《计算机软件著作权登记证书》（电子证书可直接下载）。
2. 在微信小游戏备案/资质审核页面，按要求上传证书。
3. 证书上的软件名称会作为版权证明，建议与游戏名称「赛球弹珠竞速」保持一致对应关系。
