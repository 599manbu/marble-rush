## 二、主要功能

《赛球弹珠竞速游戏软件》是一款上帝视角的弹珠障碍竞速游戏。玩家操控一颗弹珠沿纵向赛道高速下冲，通过左右转向闪避旋转风车、摆锤、活塞、弹射台、钉阵、漏斗与陷阱黑洞等机关，并在与其他弹珠的碰撞中抢占路线，最先冲过终点者获胜。

主要功能模块：

1. **模式系统**：单人（对战 AI）、双人分屏（同设备两人各控一颗）、全 AI 观赛三种模式。
2. **赛道生成系统**：程序化随机生成赛道，按难度控制机关密度，保证每排障碍均有可通行缺口。
3. **实时物理系统**：圆形刚体、旋转杆（OBB）、活塞与静态矩形的碰撞解算，弹珠之间的碰撞与动量传递。
4. **AI 系统**：多排障碍预判、可达性路线规划、阻尼转向与刹车找缺口。
5. **操作适配系统**：虚拟摇杆（模拟量转向、上推刹车）与左右按钮两种触屏操作方式。
6. **设置系统**：操作方式切换、音效音量调节、静音，设置保存在本机。
7. **成绩系统**：结算显示名次、用时、落坑次数，按赛道长度与难度分别记录本机最佳成绩。
8. **渲染系统**：Canvas 2D 实时渲染，含实时排名、顶部战况条、粒子与拖尾特效。

## 三、技术特点

1. 纯原生 JavaScript + Canvas 2D 实现，无第三方游戏引擎与素材库。
2. 自研 2D 物理：旋转杆使用局部坐标投影求解，活塞带运动速度传递。
3. AI 采用"障碍排聚类 + 通道区间 + 未来排可达性链"的路线规划，技能值决定预判深度。
4. 性能优化：机关动画惰性计算、二分空间窗口查询、名字标签离屏缓存、拖尾分段合并。
5. 界面采用虚拟坐标 + 自动缩放，适配 375–430 宽各类手机屏幕。
6. 音效由 WebAudio 振荡器实时合成，无音频文件依赖。
