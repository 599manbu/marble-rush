# 推广视频脚本（约 30 秒）

> 说明：视频需要实录游戏画面。用手机「屏幕录制」在微信里录制，再按下面的分镜剪辑即可。
> 建议 1080×1920 竖版、30fps、无背景音乐版权风险（可用微信剪映自带音乐）。

| 时间 | 画面 | 字幕 / 旁白 |
|---|---|---|
| 0–3 秒 | 比赛开始，弹珠冲下赛道，机关快速掠过 | 「一颗弹珠，冲下机关赛道」 |
| 3–8 秒 | 旋转风车击飞弹珠、活塞伸缩、弹珠掉入黑洞 | 「风车、活塞、黑洞，全程实时物理」 |
| 8–13 秒 | 关卡选择界面，滑动到第 20 关，点进关卡 | 「50 关挑战，难度逐关提升」 |
| 13–18 秒 | 通关结算显示「通关！」，返回选关看到解锁 | 「拿第一才能解锁下一关」 |
| 18–24 秒 | 邀请好友界面 → 分享卡片 → 好友进入同一赛道 | 「拉好友同赛道比用时」 |
| 24–27 秒 | 好友排行榜，显示几个好友的关卡数与用时 | 「好友排行榜，看看谁更强」 |
| 27–30 秒 | 主菜单，镜头停在「开始比赛」 | 「打开微信，立即开跑」 |

## 录制建议

1. 真机微信打开小游戏，用系统自带「屏幕录制」录 1080p。
2. 先录一段完整的 30–40 秒比赛，再录关卡选择、邀请、排行榜各 5 秒，方便剪辑。
3. 字幕用大号字、加深色描边，避免被画面吃掉。
4. 不要出现其他游戏画面、二维码、外部链接。
5. 视频里不要写「分享得奖励」等诱导分享字样。

## 提交位置

公众平台 → 推广 → 内容素材 → 推广视频 → 上传（每周可修改 10 次）。
