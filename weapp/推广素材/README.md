## 重要提醒

1. **游戏详细介绍目前平台上还是旧文案**（写着“双人分屏”），请用 `02-游戏详细介绍.txt` 替换成新版。
2. 封面不要放小游戏图标和游戏名（平台规范），当前封面只放了玩法卖点，可直接用。
3. 推广图里的截图来自当前版本（关卡/邀请/排行），如需替换，用 `weapp/assets/screenshots/` 里的图重新生成：
   - 竖版：`vertical.html`
   - 横版：`horizontal.html`
   - 分享图：`share2.html` / `share3.html`
   用浏览器打开对应 HTML，按设计尺寸截图即可。
4. 推广视频需要真机录屏，按脚本剪辑；每周可修改 10 次。
5. 分享图片上传后，可通过「转发方法」把图片编号/地址传给游戏使用（如分享卡片）。

## 智能内容运营

平台在「版本更新发布」「进入榜单」「获得官方称号」时自动生成游戏圈帖子。
建议直接点 **「前往开启」**，开发者可随时对生成内容做二次管理。
