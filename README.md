# 赛球 · Marble Rush

> 上帝视角弹珠障碍追逐赛 —— 单文件 HTML5 游戏，**双击即玩，零依赖**。

灵感来自网络上的弹珠竞速视频：几颗弹珠冲下赛道，穿过重重机关决出胜负。
在这里你亲手控制自己的弹珠，与 5 颗 AI 弹珠同场竞技。

## 运行方式

下载或克隆本仓库后，**双击 `index.html`** 即可在浏览器中游玩。无需安装任何东西、无需服务器。

**手机可玩**：手机浏览器打开即出现左下角虚拟摇杆（模拟量转向，上推刹车）；双人模式自动变为左右双摇杆；观赛模式点击顶部战况条切换视角。建议横屏游玩。

**操作方式可在 ⚙ 设置 中切换**：默认虚拟摇杆，也可换成**左右按钮**（屏幕下方 ◀=左转、▶=右转，双人模式 P1 左半边、P2 右半边）；设置里还可以**调节音效音量**与静音，全部自动保存。

**在线试玩**：https://599manbu.github.io/marble-rush/

## 游戏模式

| 模式 | 说明 |
|---|---|
| **单人** | 你（金色弹珠）对抗 5 颗 AI 弹珠 |
| **双人 · 分屏** | P1 金球 `WASD`，P2 蓝球方向键，左右分屏各自视角 + 4 颗人机 |
| **全AI观赛** | 6 颗高手弹珠同场竞技，你当解说。单屏：空格切视角；双屏：**左屏自动锁定榜首**，空格只切右屏 |

## 自由组合的选项

- **赛道长度**：短 ≈40 秒 / 中 ≈1分30 / 长 ≈2分钟 / 超长 ≈3分钟
- **AI 难度**：简单 / 普通 / 困难 / 噩梦（决定人机技术、速度与机关密度）
- **小球数量**：1-10 颗，10 种固定颜色各不相同
- **选手命名**：每颗球都可以自定义名字（自动保存本地）

## ⚙ 设置

主菜单与比赛中（底部中间）都可以打开设置面板：

| 选项 | 说明 |
|---|---|
| **操作方式** | 虚拟摇杆（左下推动转向、上推刹车）/ 左右按钮（屏幕下方 ◀ 左 · ▶ 右） |
| **音效音量** | 0-100% 实时生效，可试听；`音效 开/关` 一键静音（同 `M` 键） |

操作方式与音效设置保存在本机（localStorage），下次打开自动恢复。

## 机关类型

石门关隘 · 错位石门阵（S 形走线）· 旋转风车 · 墙边摆锤 · 来回活塞 · 弹射台 · 钉阵 · 漏斗 · 陷阱黑洞

赛道由程序随机生成：障碍全程均匀分布，每个机关阵按实际高度排布互不重叠，生成逻辑保证**每排都有可通行缺口**。

## 操作

| 按键 | 功能 |
|---|---|
| `← →` / `A D` | 转向 |
| `↑` / `W` | 刹车 |
| `空格` / `1-6` / 点击 | 观赛模式切换视角 |
| `R` / `P` / `M` / `Esc` | 重开 / 暂停 / 静音 / 返回菜单 |

## 技术亮点

- 纯 HTML5 Canvas + 原生 JavaScript，**单文件、零依赖**
- 实时 2D 物理：圆形/旋转杆（OBB）/ 活塞碰撞、球间对抗
- 高级 AI：多排障碍预判 + 可达性路线规划 + 阻尼转向 + 刹车找缺口
- 性能优化：机关动画惰性计算、二分空间窗口、渲染缓存（最长赛道双屏渲染 85+ FPS）
- WebAudio 合成音效（无音频文件）

想调手感：`GY`（重力）、`DRAG`（阻力）两个常量；想调难度：`AILVLS` / `LENGTHS` 两张表。
